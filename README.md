# 🎼 IJO — 악보 이조 프로그램

브라우저에서 바로 쓰는 악보 이조(조옮김) 프로그램입니다. 설치나 서버가 필요 없고, 파일은 외부로 전송되지 않습니다.

## 기능

| 구분 | 내용 |
|---|---|
| **PDF · 사진 악보** | 글자로 된 코드 악보 PDF는 텍스트를 읽어 코드 악보로 바로 이조. 오선 악보 PDF·사진은 Claude가 읽어서 MusicXML로 변환 (claude.ai 아티팩트에서 열었을 때) |
| **오선 악보 (MusicXML)** | `.musicxml` / `.xml` / `.mxl` 파일을 열어 이조 → 화면에 악보 표시, MusicXML 다운로드, 인쇄/PDF 저장 |
| **코드 악보 (텍스트)** | 가사 위 코드 줄 형식과 `[C]가사` ChordPro 형식 모두 지원, 가사와의 칸 맞춤 유지 |
| **이조 방법** | 목표 조 선택(위/아래/가까운 쪽) · 반음 단위 이동 · 이조악기 프리셋(B♭ 트럼펫·클라리넷, 테너/알토/바리톤 색소폰, F 호른) |
| **올바른 음 표기** | 새 조표에 맞춰 음 이름을 정함 (예: C장조의 F♯ → B♭장조에서는 E♮, D♭장조로 가면 G♮) |
| **♯/♭ 선택** | 자동(조표가 적은 쪽) / ♯ 우선(C♯, F♯) / ♭ 우선(D♭, G♭) |

MusicXML에서는 조표, 음표(옥타브 포함), 임시표, 코드 심볼(근음·베이스음)을 모두 이조합니다.

## 실행

ES 모듈을 사용하므로 `index.html`을 파일로 바로 열지 말고 간단한 로컬 서버로 여세요.

```bash
python3 -m http.server 8080
# 또는
npm start
```

그다음 브라우저에서 <http://localhost:8080> 을 엽니다. GitHub Pages 같은 정적 호스팅에 그대로 올려도 동작합니다.

## PDF · 사진 악보

- **코드 악보 PDF**(글자를 복사할 수 있는 PDF): 글자 위치로 코드 줄과 가사 줄을 복원해 코드 악보 탭에 넣습니다.
- **오선 악보 PDF·스캔·사진**: claude.ai 아티팩트 화면에서 Claude가 읽어 MusicXML로 만듭니다 (보는 사람의 Claude 사용량 사용).
  1. 페이지에서 오선을 자동으로 찾고(기울어진 스캔 보정), 번호를 붙인 이미지로 단(system)을 묶습니다.
  2. 단마다 잘라 크게 보내 받아 적게 합니다. 한 오선에 두 성부, 피아노 큰보표, 가사(여러 절), 셈여림, 빠르기말·rit., 이음줄, 붙임줄, 꾸밈음, 늘임표, 셋잇단을 지원합니다.
  3. 마디 길이가 박자표와 안 맞는 단은 문제 목록과 함께 한 번 더 검토시킵니다.
  4. (정밀 인식, 기본 켜짐) 받아 적은 결과를 악보 그림으로 다시 그려 원본 이미지와 나란히 보여 주고, 다른 음·리듬을 찾아 고치게 합니다.
  단마다 1~2분 걸리고(2개씩 동시 처리), 자동 인식이라 틀린 음이 있을 수 있으니 "원본 페이지 보기"로 비교해 주세요.
- 정확도가 중요하면 MuseScore 4의 "PDF 가져오기"나 Audiveris로 변환한 MusicXML을 넣는 방법도 있습니다.

## 구조

```
index.html, style.css   화면
src/theory.js           조표·음 이름·이조 계산 (핵심 로직)
src/musicxml.js         MusicXML 이조
src/chords.js           코드 악보 텍스트 이조
src/pdf.js              PDF 텍스트 추출·페이지 이미지 변환 (pdf.js)
src/layout.js           악보 이미지에서 오선·단 위치 찾기
src/omr.js              악보 인식 프롬프트, 결과 검사·병합, JSON → MusicXML
src/app.js              화면 동작
test/                   단위 테스트 (npm test)
```
